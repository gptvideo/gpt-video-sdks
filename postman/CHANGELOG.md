# Changelog

## 1.0.0

The first version, for version 1 of the GPT-Video API.

- Every operation of the API, in folders, and a Quickstart folder that takes a video to a finished clip.
- An environment with `apiKey`, `baseUrl` and `idempotencySalt`.
- An Idempotency-Key made by the pre-request script, the same for the same request.
